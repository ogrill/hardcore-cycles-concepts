# Hardcore Cycles — Existing Website, Refined

This is a faithful design improvement of the public Squarespace site (not a replacement for the actual live business website). Preserves the shop's original logo and current photographs; retains the Home/Services/Store/History/Visit Us site structure; corrects contact details and reduces repetitive promotional copy. The Store link points to the existing Squarespace store. The waving American flag is drawn and animated with a real 50-star, 13-stripe arrangement via lightweight canvas code. No shop customer data, booking system, payment flow, or email is accessed or sent.

Pages: index.html, services.html, history.html, visit.html. Includes interactive mobile navigation, clickable phone/email/directions, and a reduced-motion flag fallback.

All company information, product claims, hours, and individual names should be confirmed with the shop prior to replacing its own site. Photo and logo assets are sourced from the business's public website for internal review; obtain approval before broader distribution.
